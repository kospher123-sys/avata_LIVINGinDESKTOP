# v0.8 — 중복 실행 방지·일시정지·숨기기

```powershell
.\.venv\Scripts\python.exe prototype_v0_8\main.py --settings
```

트레이의 컴퓨터 아이콘을 우클릭해서 조작합니다.

- **일시정지 / 재개**: 캐릭터 위치·애니메이션·앉기/일어서기 진행을 멈추거나 이어갑니다.
- **숨기기 / 다시 표시**: 캐릭터를 감추고 동작도 정지합니다. 트레이와 설정은 사용할 수 있습니다.
- 두 상태는 독립적입니다. 일시정지한 뒤 숨겼다가 표시하면 계속 일시정지 상태입니다.
- 일시정지·숨김은 실행 중에만 적용하며 재실행 시 기본 표시/활동 상태로 시작합니다. 저장된 시간표가 휴식 시간이라면 휴식 상태를 따릅니다.
- 재개 시 기다린 시간을 이동량으로 합산하지 않고 현재 시각으로 시간표를 다시 확인합니다.
- 같은 사용자 환경의 v0.8을 다시 실행하면 새 캐릭터를 만들지 않고 기존 앱의 설정 창을 엽니다. 숨김/일시정지는 그대로 유지합니다.
- 비정상 종료 후에도 다시 실행할 수 있도록 종료된 프로세스의 잠금을 정리합니다.
- v0.7 이전 버전에는 중복 실행 보호가 없습니다. 구버전과는 동시에 실행하지 마세요.

기존 실시간 설정·탭·초기화·매일 반복 시간표·모니터 선택·휴식 이미지 연결 준비는 유지합니다. 요일별 시간표는 개발 범위에서 제외했습니다. 이미지 파일 규격은 [휴식 이미지 안내](../docs/REST_ASSET_IMPORT.md)를 참고하세요.

검사:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s prototype_v0_8 -v
```

실제 휴식 이미지 검수와 다중 모니터 실기기 검사는 아직 대기 중입니다.
