# v0.11 — 설정 창에서 휴식 동작 한 번 확인

```powershell
.\.venv\Scripts\python.exe prototype_v0_11\main.py --settings
```

**동작 확인** 탭에서 **전체 동작 한 번 보기**를 누르면 앉기 → 앉은 대기 한 바퀴 → 일어서기를 재생합니다. 설정 창은 유지되고 크기/속도/시간표를 저장하거나 변경하지 않습니다. 완료하면 원래 동작 모드를 따르며, 현재 휴식 시간이면 다시 앉아서 쉽니다.

- **확인 종료**로 중간에 종료할 수 있습니다. 정상 동작 모드가 자동이면 현재 시간표에 맞춰 전환합니다.
- 일시정지·숨김 상태에서는 새 재생을 시작하지 않습니다. 재생 도중 일시정지하면 진행도 멈추고 재개 후 이어집니다.
- 트레이에서 걷기/대기/자동 등을 직접 고르면 동작 확인을 종료하고 선택한 모드로 바꿉니다.
- 트레이의 **휴식 동작 한 번 보기** 또는 실행 옵션 `--preview-once`로도 시작할 수 있습니다.
- 기존 **휴식 모션 확인**은 계속 앉아 있는 반복 확인입니다. `--preview-rest`도 같은 기존 기능입니다.
- 확인 시작 시 서 있는 자세부터 다시 재생합니다. 반복 클릭으로 여러 재생이 겹치지 않도록 방지합니다.

이미지는 v0.10과 동일하며 새 이미지 생성이나 원본 픽셀 변경은 없습니다. 프레임별 시간과 기준점은 assets/characters/aang/clips.json을 사용합니다.

Windows 배포:

```powershell
.\.venv\Scripts\python.exe prototype_v0_11\build_windows.py
```

결과는 dist/AangOverlay-v0.11 폴더입니다. 전체 폴더가 필요하며 exe만 따로 옮기지 마세요. 이전 버전과 같은 사용자 설정과 실행 잠금을 사용하므로 동시에 실행하지 않습니다.

자동 검사:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s prototype_v0_11 -v
```

실제 절전·장시간·다중 모니터와 모션 자연스러움은 별도 사용자 검수가 필요합니다. 요일별 시간표는 제외했습니다.
