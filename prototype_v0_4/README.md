# v0.4 — 설정 창과 설정 저장

저장소 루트의 PowerShell에서 실행:

```powershell
.\.venv\Scripts\python.exe prototype_v0_4\main.py
```

설정 창을 함께 열려면 끝에 `--settings`를 붙입니다.
트레이의 컴퓨터 아이콘 우클릭 → **설정…**에서도 열 수 있습니다.

- 기본 캐릭터 높이 **120px**. 수동 범위 80~240px, 이동 속도 10~150px/초.
- 자동 크기는 화면의 논리 높이 900px에 캐릭터 120px 비율로 계산하고 80~240px로 제한합니다. Windows 배율은 Qt 화면 좌표에 이미 반영됩니다. 크기는 투명 여백을 제외한 공통 캐릭터 영역 기준입니다.
- 수동 높이는 자동 크기를 켜도 보존됩니다. 자동 크기를 끄면 다시 사용할 수 있습니다.
- 크기·속도·자동 크기·자동 이동은 변경 즉시 미리보기에 반영되며 설정 창은 열린 상태로 유지됩니다.
- **저장**하면 파일에 보관하고 재실행 시 복원됩니다. 취소하거나 창을 닫으면 미리보기 변경을 취소하고 저장된 설정으로 돌아갑니다.
- 자동 이동을 끄면 대기합니다. 트레이의 대기/걷기는 임시 확인용이며 저장되지 않습니다. 설정 저장 시 자동 모드로 돌아옵니다.
- 설정은 Windows 사용자별 `%LOCALAPPDATA%/AvatarLivingInDesktop/AangOverlay/settings.ini`에 저장합니다. 저장소와 분리됩니다. 손상된 값은 기본값 또는 허용 범위로 복구합니다.
- 투명 배경, 항상 위, 기본 클릭 통과, 선택적 드래그 모드, 방향 반전과 종료는 v0.3에서 유지했습니다.
- 크기 적용 시 작업표시줄 위로 돌아옵니다. 기본 모니터만 사용하며 모니터 선택 및 다중 모니터 이동은 후속 범위입니다.

자동 검사:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s prototype_v0_4 -v
```

v0.3은 별도로 보존했습니다. 두 버전을 동시에 실행하면 캐릭터가 중복 표시됩니다.
