# v0.3 — 아앙 스프라이트 오버레이

기존 v0.2는 보존하고 실제 투명 PNG 대기 4장·걷기 6장을 연결한 버전입니다.

저장소 루트의 PowerShell에서 실행:

```powershell
.\.venv\Scripts\python.exe prototype_v0_3\main.py
```

120px로 시작하려면 `--height 120`을 붙입니다. 실행 중에도 트레이 메뉴에서 크기를 바꿀 수 있습니다.

새 환경은 `python -m pip install -r prototype_v0_3/requirements.txt`로 준비합니다.
이미지 경로는 실행 폴더와 무관하게 코드 위치를 기준으로 찾습니다.

- 기본: 항상 위, 투명 배경, 클릭 통과, 자동 대기/걷기, 좌우 끝 반전.
- 시스템 트레이의 컴퓨터 아이콘을 우클릭하면 동작, 높이 120/150/180px, 방향 전환, 종료를 선택할 수 있습니다.
- 드래그 모드를 켜면 캐릭터 창에서 왼쪽 드래그와 우클릭 메뉴를 사용할 수 있습니다. 끄면 클릭 통과로 복귀합니다.
- 높이는 투명 여백을 제외한 전체 프레임 공통 영역(원본 396px) 기준이며 기본 150px입니다.
- 공통 캔버스와 발 기준점 (148,419)을 같은 비율로 그리며, 초기 발 위치를 작업표시줄 위에 맞춥니다.
- 대기는 프레임당 320ms, 걷기는 120ms. 상태 변경 시 첫 프레임부터 재생합니다.
- 기본 모니터만 지원합니다. 드래그로 높이를 옮기면 해당 높이에서 좌우 이동합니다. 크기 변경 시 바닥으로 복귀합니다.

에셋 외곽의 밝은 프린지 및 포즈 자체의 흔들림은 남을 수 있습니다. 다중 모니터, 독점 전체화면, 절전 복귀는 미검증입니다.
