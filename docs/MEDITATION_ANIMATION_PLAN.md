# 휴식 전용 명상 모션 — 기본 포즈 초안

> 후속 결정: 이미지는 사용자가 별도 제작한다. 이 문서의 초안 검토/생성 순서는 참고 이력이며 더 이상 이미지 제작을 진행하지 않는다. v0.7 소스 연결 준비는 완료했으며 현재 배치 규격은 [REST_ASSET_IMPORT.md](REST_ASSET_IMPORT.md)를 따른다. 아래 앱 상태는 초안 작성 당시의 기록이다.

> 초안 이미지·생성 기록·검수 원자료는 로컬에만 보존하고 Git에서 제외했다. GitHub에는 소스코드와 제작/배치 규격 문서만 반영한다.

2026-11-08 사용자가 휴식 동작으로 '앉아서 명상하기'를 선택했다.

## 현재 결과

- 확정된 성인 남성 공기 승려 마스터를 참고하여 오른쪽을 향해 가부좌로 앉아 눈을 감고 손을 모은 기본 포즈를 생성했다.
- 생성 원본 v1/v2는 `assets/characters/aang/reference/meditation/`에 비파괴 저장했다. v2 캔버스 1024×1536, 알파 채널과 실제 투명 픽셀 확인. 상세 수치는 같은 폴더 validation.json에 있다.
- 회색 배경에 QPainter로 표시하여 실제 알파가 적용된 모습을 확인했다. 생성 이미지 미리보기에서 보인 넓은 빛 번짐은 이 렌더링에서 표시되지 않는다. 다만 alpha>0 범위에 작은 잔여 픽셀이 있어 런타임 품질 통과로 판정하지 않는다.
- 이 이미지는 포즈 검토용 초안이다. 기존 296×444 IDLE/WALK 대비 외형 크기, 몸통 기준점 및 지면 정렬, 외곽 무결성은 아직 최종 확정하지 않았다. 정지 포즈는 호흡 애니메이션이나 전환 애니메이션을 대신하지 않는다.

## 다음 제작 순서

1. 기존 제작 절차에 따라 기본 포즈의 외형과 자세를 사용자 검토 후 확정한다.
2. 동일 캐릭터 크기와 공통 기준점 (148,419)에 맞춘 런타임 규격을 결정한다. 앉았다는 이유로 포즈를 확대하여 원래 서 있을 때와 키를 같게 만들지 않는다. 설정의 120px는 기존 서 있는 캐릭터의 크기 기준으로 유지한다.
3. 명상 중립 → 미세한 들숨 → 들숨 정점 → 날숨의 4프레임을 제작하고, 처음에는 프레임당 약 500ms로 루프를 검토한다. 몸통·얼굴이 튀지 않도록 머리 크기와 바닥 접점을 고정한다.
4. 서기→앉기와 앉기→서기의 전환 모션을 제작한다. 걷는 중 휴식 시작 시 즉시 좌표가 튀거나 다른 크기의 포즈로 바뀌지 않도록 한다.
5. REST/전환 상태를 행동 모델에 추가하고 시간표에 연결한다. 명상/전환 에셋이 없거나 유효하지 않으면 기존 IDLE로 대체한다.
6. 투명도·외곽, 공통 배율·좌우 반전, 반복 루프, 휴식/활동 전환과 실제 120px 오버레이를 검수한다.

## 현재 앱 상태

v0.6은 그대로 실행 중이다. 휴식 시간에는 기존 IDLE 4프레임을 사용하며 새 이미지로 교체하지 않았다. 새 애니메이션 제작·v0.7 앱 연결·GitHub 반영은 미수행이다.
