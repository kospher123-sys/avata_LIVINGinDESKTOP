# 사용자가 제작하는 휴식 이미지 배치 규격

새 이미지는 사용자가 제작하며, 코드는 이미지가 없는 상태에서도 실행됩니다. 기존 생성 초안은 참고 폴더에 보존할 뿐 자동으로 사용하지 않습니다.

## 폴더와 파일명

저장소 루트의 `assets/characters/aang/` 아래에 원하는 동작 폴더를 넣습니다.

```text
rest/rest_01.png, rest_02.png, ...             명상 호흡 루프 (권장 4장)
sit_down/sit_down_01.png, sit_down_02.png, ...  서기→앉기 (권장 3장 이상)
stand_up/stand_up_01.png, stand_up_02.png, ...  앉기→서기 (권장 3장 이상)
```

각 동작은 01부터 빠짐없이 번호를 붙입니다. 동작당 1~32장을 허용하므로 실제 제작 장수에 맞출 수 있습니다. 검토용 PNG는 런타임 동작 폴더 밖에 보관하세요.

## 이미지 규격

- 실제 투명 배경 PNG, 공통 캔버스 **296×444**. 코드에서 크기와 알파 채널, 투명 픽셀 및 보이는 픽셀 존재를 검사합니다. 외곽 품질이나 자세의 정확성은 별도 시각 검수가 필요합니다.
- 원점은 좌상단, 기준점 **(148,419)**. 앉아 있을 때는 바닥에 닿는 옷/신체와 공통 지면을 맞추고 머리·몸통 크기는 기존 캐릭터와 유지합니다.
- 앉은 자세를 캔버스에 가득 채우려고 확대하지 않습니다. 120px 설정은 기존 서 있는 캐릭터의 높이를 기준으로 같은 배율을 적용합니다.
- 오른쪽을 향한 시점, 의상·신체 비율·선 두께·색을 유지합니다. 왼쪽 방향은 같은 기준점을 중심으로 반전합니다.
- 명상 프레임은 500ms/장, 앉기·일어서기는 150ms/장으로 시작합니다. 호흡은 반복하고 전환 동작은 한 번만 재생합니다.

## 앱에서 확인

1. 파일을 다 복사한 후 트레이 또는 생활 시간표 탭에서 **이미지 다시 불러오기**를 누릅니다.
2. 생활 시간표 탭에 명상 프레임 준비 상태가 표시됩니다. 규격 오류가 있으면 해당 동작 전체를 제외하고 설명을 툴팁에 표시합니다.
3. 트레이 → 동작 → **휴식 모션 확인**으로 확인합니다. 검사 후 **자동**으로 돌아오면 저장된 시간표를 따릅니다.

명상이 없으면 IDLE로 표시하며 앉기/일어서기도 사용하지 않습니다. 명상만 있으면 즉시 명상으로 전환하고, 전환 이미지가 있으면 함께 재생합니다. 앉기·명상·일어서기 동안 화면상의 이동을 멈추고 일어서기가 끝난 뒤 이동을 재개합니다.

기존 필수 IDLE/WALK가 잘못되면 재불러오기를 거부하고 직전 이미지 세트를 유지합니다. 선택적 휴식 이미지가 잘못되면 가능한 동작으로 대체합니다. 재불러오기는 새 세트를 한 번에 교체하고 현재 전환 진행을 초기화합니다.

이미지 전환 중 시간표를 다시 바꾸면 새 요청에 해당하는 전환의 첫 프레임부터 시작합니다. 전환 중간 포즈를 자연스럽게 이어 붙이거나 역재생하는 기능은 아직 없습니다. 임시 대기/걷기·드래그는 전환보다 우선하며 즉시 해당 동작으로 바꿉니다.
