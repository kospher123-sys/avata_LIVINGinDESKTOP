# v0.9 검증 기록 — 2026-11-08

## 구현 및 환경

- Python 3.11.9 / PySide6 6.12.0, Windows x64.
- PyInstaller 6.22.3으로 폴더형 Windows 앱 제작. 자원 검사는 psutil 7.2.2 사용.
- 절전 복귀 알림 또는 10초 초과 타이머 공백/시계 역행 감지 후 750ms에 복구 작업을 모아서 수행한다. 화면 영역/자동 크기/설정 창 위치를 복구하고 현재 시각에 맞춰 시간표를 재평가한다. 일시정지/숨김은 유지한다.
- 사용자별 로그 폴더의 app.log는 UTF-8, 약 1MB×최대 4개. 시작/정상 종료·이미지 오류·설정 저장·복구·예외 기록. 서버 전송 없음.

## 자동 검사

`python -m unittest discover -s prototype_v0_9 -v`: **32개 통과**.

기존 설정/시간표/휴식 에셋 대체/중복 실행/표시 제어에 복구 요청 합치기, 화면 밖 설정 창 복원, 숨김/정지 유지, 타이머 공백/복귀 이벤트 판별, 실행 파일의 이미지 경로 및 UTF-8 로그 순환 검사를 추가했다.

## Windows 실행 파일

- `dist/AangOverlay-v0.9/AangOverlay-v0.9.exe` 빌드 성공. 폴더 전체 약 111.7MB, IDLE 4장/WALK 6장 포함. 추가 휴식 이미지는 없음.
- 프로젝트 폴더 밖의 Windows 임시 폴더를 작업 경로로 시작하여 `--settings --quit-after 8` 실행: 정상 시작 및 종료 코드 0, packaged=True와 정상 종료 로그 확인.
- 배포 실행 파일이 실행 중일 때 소스 v0.9로 다시 시작: 두 번째 실행 코드 0, 기존 앱 프로세스 응답 유지. 중복 캐릭터용 새 주 실행 프로세스를 만들지 않는다.
- 배포본 내부 코드에 수정된 설정 창 높이 계산 및 종료 정리 함수가 포함됨을 확인했다. 빌드 경고의 누락 항목은 Windows에서 사용하지 않는 플랫폼별 선택 모듈이었다.

## 2분 반복 자원 검사

`python prototype_v0_9/soak_check.py --seconds 120 --output reports/soak-v0.9-120s.json`.

- 실제 120.33초, Qt offscreen, 임시 설정 사용. 걷기/일시정지/숨기기/복구 및 설정 창 열고 닫기를 반복했다.
- 상태·경계 검사 통과, 예외 0건.
- 초기 구간 제외 측정 RSS 약 51.64~55.08MB, 구간 시작 대비 +3.42MB. 설정 창을 처음 연 뒤 약 55MB 근처였으며 이 짧은 관찰만으로 메모리 누수 유무를 확정하지 않는다.
- 프로세스 평균 CPU 3.53%(psutil 방식), 샘플 핸들 수는 279에서 280으로 증가 후 관찰 구간에서 유지됐다. CPU는 별도 화면 환경과 검사 부하가 포함된 참고값이다.
- 원자료 JSON은 로컬 reports/에 보존하고 Git에서 제외했다. 같은 스크립트로 600초 또는 28800초 검사가 가능하다.

## 아직 검증하지 않은 것

실제 시스템 절전 및 복귀, 하루 이상의 실제 바탕화면 사용, 독점 전체화면, 실제 외부 모니터 분리/재연결, 사용자가 제공할 명상/전환 이미지의 자연스러움. 2분 offscreen 검사를 장시간 또는 실제 절전 검증으로 간주하지 않는다.

## 설정 창 표시 수정 — 후속 검증

- 사용자 보고 후 실제 Windows 창을 확인했다. 실행 파일을 숨김 방식으로 시작한 영향이 있었고, 일반 표시로 재실행하자 설정 창이 나타났다. 추가로 캐릭터가 화면 아래에 있어 설정 창도 아래쪽에서 열려 일부가 잘리는 문제를 확인했다.
- 설정 열기에서 일반 창 표시, 사용 화면 중앙 배치, 화면 작업 영역 안으로 위치 보정을 적용했다. 이미 열려 있는 창도 요청 시 화면 안으로 복원한다. 새로 실행할 때는 일반 표시 방식으로 시작한다.
- 설정 창의 전체 프레임이 화면 안에 있고 화면 중앙에 열리는 검사 및 재요청 복원 검사를 추가하여 총 **33개 자동 검사 통과**. 실제 Windows 설정 창의 위치와 버튼 전체 표시도 확인했다.
