- `clips.json`에 동작 폴더·파일 접두사·캔버스·기준점·서기 높이·프레임별 시간을 기록했다. 512×768의 (256,735), 서기 높이 680을 기존 논리 좌표의 (148,419), 서기 높이 396에 대응시킨다.

- 이전 폴더 규격도 지원한다. 잘못된 clips.json/선택적 동작은 경고하고 기존 동작으로 대체한다.
- `--preview-rest` 또는 트레이의 휴식 모션 확인으로 시간표를 바꾸지 않고 시험할 수 있다. 자동으로 복귀하면 일어서기를 재생한 뒤 시간표를 따른다. 임시 걷기/대기는 즉시 바꾸는 확인용 동작이다.
