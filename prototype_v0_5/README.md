# v0.5 — 머물 화면 선택과 모니터 변경 대응

저장소 루트의 PowerShell에서 실행:

```powershell
.\.venv\Scripts\python.exe prototype_v0_5\main.py --settings
```

트레이 아이콘 우클릭 → **설정…** → **머물 화면**에서 화면을 고릅니다.

- 기본은 **기본 화면 따라가기**. 화면 이름, 해상도와 배율을 함께 표시합니다.
- 화면 선택은 즉시 미리보기에 반영됩니다. 저장하면 재실행에도 유지하고, 취소/닫기는 이전 선택으로 돌아갑니다.
- 선택한 모니터가 없으면 기본 화면을 사용하고 저장된 선택을 보존합니다. 재연결되면 다시 선택한 모니터로 돌아갑니다.
- 선택한 화면의 작업 영역 안에서 걷고 작업표시줄 위에 발을 맞춥니다. 왼쪽/위쪽에 배치된 보조 화면의 음수 좌표도 처리합니다.
- 자동 크기는 선택한 화면의 Windows 배율이 반영된 논리 높이를 사용합니다. 해상도·배율·작업 영역 변경 시 다시 계산합니다.
- 수동 크기 80~240px(기본 120), 속도 10~150px/초, 자동 이동, 실시간 미리보기와 저장/취소 동작은 유지합니다.
- v0.4와 동일한 사용자별 설정 파일을 사용하므로 기존 크기와 속도를 이어받습니다.
- 일련번호가 있으면 제조사/모델/일련번호로, 없으면 화면 이름으로 식별합니다. 일련번호 없는 모니터의 포트/이름이 바뀌면 다시 선택해야 할 수 있습니다.
- 화면 사이를 걸어서 넘어가는 기능은 후속 범위입니다. 드래그는 선택한 화면 안에서만 동작합니다.

자동 검사:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s prototype_v0_5 -v
```

저장/취소/미리보기와 모의 화면 전환·분리·재연결·음수 좌표를 검사합니다. 실제 다중 모니터, 절전 복귀와 독점 전체화면은 추가 실기기 검증이 필요합니다.

v0.4는 별도 보존했습니다. 두 버전을 동시에 실행하면 캐릭터가 중복 표시됩니다.
