# v0.6 — 시간대별 생활 패턴

저장소 루트에서 실행:

```powershell
.\.venv\Scripts\python.exe prototype_v0_6\main.py --settings
```

설정 창에서 **생활 시간표 사용**을 켜고 **휴식 시작 / 활동 재개** 시간을 정합니다.

설정은 **화면·크기 / 움직임 / 생활 시간표** 탭으로 구분됩니다. 각 시간 입력 옆의 **현재시간** 버튼은 컴퓨터의 현재 시각을 해당 항목에 넣고 즉시 미리보기에 반영합니다. 시간표와 자동 이동이 켜져 있을 때 사용할 수 있습니다. 탭을 옮겨도 편집 내용이 유지되며 저장/취소는 모든 탭에 함께 적용됩니다.

**시간표 초기화**는 시간표 사용을 끄고 휴식 시간을 22:00~07:00으로 되돌립니다. 다른 탭의 편집 내용은 유지합니다. 하단의 **전체 설정 초기화**는 모든 탭을 기본값(높이 120px, 자동 크기 꺼짐, 속도 75px/초, 자동 이동 켜짐, 기본 화면 따라가기, 시간표 꺼짐·22:00~07:00)으로 되돌립니다. 두 초기화 모두 미리보기만 바꾸므로 저장 전 취소/닫기로 기존 설정을 복원할 수 있습니다.

- 기본 시간표는 22:00~07:00 휴식이며, 처음에는 시간표가 꺼져 있어 기존처럼 자유롭게 걷고 쉽니다.
- 시간표를 켜면 휴식 시간에는 대기, 활동 시간에는 기존의 대기/걷기 패턴을 사용합니다. 별도 수면 이미지는 사용하지 않습니다.
- 컴퓨터의 현재 로컬 시각을 기준으로 매번 판단합니다. 자정을 넘는 휴식 구간도 지원하고, 시작 시각은 포함하며 종료 시각은 포함하지 않습니다.
- 두 시각이 같으면 휴식 구간이 없는 것으로 처리합니다. 시간표는 매일 반복되며 요일 구분이나 가상 시간 배속은 후속 범위입니다.
- 자동 이동을 끄면 시간표보다 우선하여 대기합니다. 트레이의 임시 대기/걷기는 시간표보다 우선하며 자동 모드로 돌아오면 시간표를 따릅니다.
- **지금 아앙은**에서 현재 시간표 상태 또는 임시 동작을 확인할 수 있습니다.
- 시간표 변경도 즉시 미리보기로 반영합니다. 저장하면 재실행 시 복원하고, 취소/닫기는 저장된 설정으로 돌아갑니다.
- 모니터 선택, 기본 높이 120px, 크기/속도 미리보기, 기본 클릭 통과와 드래그 모드는 유지합니다.
- 이전 버전과 같은 사용자별 설정 파일을 사용하여 저장된 크기/속도/모니터를 이어받습니다.

자동 검사:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s prototype_v0_6 -v
```

시간 경계·자정·활동 복귀·임시 동작 우선순위·설정 저장/취소 및 기존 화면/설정 기능을 검사합니다. 실제 하루 장시간 실행, 절전 복귀와 외부 모니터는 추가 검증이 필요합니다.
