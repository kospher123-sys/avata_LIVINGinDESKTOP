## 입력 대응과 문서 차이

문서와 이번 첨부 파일의 번호·파일명이 다르므로 포즈로 역할을 연결했다. 이번 첨부 1=A 측면 서기, 5=B 정면 서기, 2=C 정면 앉기, 6=앉기(SIT_DOWN), 4=일어서기(STAND_UP), 3=앉은 대기다. 원본 포즈 순서는 바꾸지 않았다. 문서의 시트 역할 번호와 실제 이번 포즈 방향이 반대이므로, 잘못된 방향으로 동작을 재생하지 않도록 실제 자세에 맞게 이름을 지정했다.

이번 C와 두 전환 시트는 RGB다. 문서에 적힌 C·E의 RGBA/253 알파 전제를 이 파일에 적용하지 않았다. A·B만 원래 RGBA이며 본체의 주된 알파 253을 강제로 255로 올리지 않았다.

## 보정 내용

원본 여섯 장과 요청 문서는 source 폴더에 보존했다. 원본 PNG 작업 전후 SHA-256은 동일하다. 이미지 편집 도구의 시도에서 생긴 빛 번짐·색 잔점 결과는 이 패키지에 사용하지 않았다. 사용자가 승인한 Python 픽셀 보정으로 원본을 처리했다.

RGBA 파일은 알파가 낮은 외곽 오염만 제한적으로 줄였다. alpha<80은 제거하고 80~220 경계를 완화했으며, 본체 고알파 영역과 RGB는 유지했다. 선명한 빨강·노랑 잔상 후보는 저알파 외곽에서만 제거했다. RGB 파일은 검정 배경을 분리하면서 갈색 부츠와 어두운 윤곽을 유지했다. 거의 검은 경계는 알파를 추정하고 검정 매트 혼합을 보정했다. 넓은 배경 및 신체 사이 검정 빈 공간은 투명해졌다.

연결 성분이 150px보다 작은 독립 잔점은 제거했다. 이는 휴리스틱이며 신체 의미를 완전히 판별하는 방법은 아니다. 정지 확인에서 큰 손·무릎·부츠 성분은 보존되었다. 일어서기 시트의 고명도 후보 55픽셀은 작은 독립 잔점으로 제거되었다. A·B·C 및 다른 시트의 고알파/고명도 후보 제거 수는 0이다. RGB 추출에서 매우 어두운 픽셀의 실제 의미는 원본 알파 부재로 완전 복원할 수 없다.

얼굴·문양·의상 구조와 원본 포즈는 다시 그리지 않았다. 원본 해상도 보정본 masters/*_clean.png 및 sheets/*_clean.png를 따로 제공한다. 이 파일들은 확대 검수에 사용하고, 정렬본은 frames 폴더에 있다.

## 캔버스·배율·앵커

정렬본은 모두 512×768 RGBA, 바닥 y=735다. 서기 기준 높이는 약 680px이다. 앉은 자세에 서기 높이를 강제하지 않았다. 각 시퀀스 전체에 하나의 배율을 적용해 원래 신체 움직임과 높이 변화를 유지했다. 가로 정렬은 머리 상단의 단면 중심 추정치로 맞췄으며, 정확한 해부학적 앵커는 아니다. 세로 정렬은 각 프레임의 가시 하단을 접지선에 맞췄다.

|원본 역할|적용 배율|
|---|---:|
|A_side_standing|0.463531|
|B_front_standing|0.463531|
|C_front_seated|0.463531|
|sit_down|0.995608|
|stand_up|1.046154|
|seated_idle|0.702476|

A·B·C에는 동일 배율을 적용했다. 두 전환 시퀀스는 각 측면 서기 끝점으로 배율을 추정했고, 앉은 대기는 앉기 마지막 프레임의 머리 폭에 맞췄다. 앉은 대기의 배율은 약 0.7025로 문서의 약 1.43배 차이와 부합한다. 모든 앵커와 원본 셀 좌표·bbox·배율은 data/validation.json에 기록했다. 이 배율은 최종 수동 확정값이 아니며 상태 경계에서 약간의 머리·몸통 크기 차이가 남을 수 있다.

## 납품 파일과 재생 설정

frames/side_idle 1장, front_idle 1장, seated_master 1장, sit_down 6장, seated_idle 4장, stand_up 6장: 총 19장. masters는 원본 해상도 보정 마스터 3장, sheets는 원본 크기 보정 시트 3장과 정렬 시트 3장이다.

앉기 시간(ms): 180,140,160,200,240,260. 일어서기: 260,240,200,160,140,180. 앉은 대기: 600,320,100,600. 이 값은 눈 감김을 짧게 하고 압축된 전환 구간을 길게 보여주는 초기 검수값이며 실제 시간 기반 관찰로 확정한 값은 아니다. 전환 GIF는 1회 재생이고 앉은 대기만 무한 반복이다. state_sequence.gif는 SIDE_IDLE→앉기→앉은 대기→일어서기→SIDE_IDLE을 한 번 보여준다. GIF 배경은 검수용 회색이고 투명 에셋은 PNG다.

- 실제 시간 기반 재생 관찰: 미검증. 로컬 미리보기 페이지의 브라우저 접근이 도구 보안 정책에서 제한되어 재생 관찰을 완료하지 못했다. GIF 디코딩 검사를 재생 관찰로 간주하지 않았다.
- Windows/PySide6 실제 알파 합성·상태 전환: 미검증. 실행 코드가 이번 입력에 없으므로 통합 검수를 수행하지 않았다.
