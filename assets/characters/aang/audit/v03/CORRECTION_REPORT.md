# Avatar Living in Desktop v0.3 — 에셋 보정 리포트

보정일: 2026-11-08 (한국 시간)

## 판정: WARNING

프레임 추출·실제 투명 RGBA·동일 캔버스·발 기준선·PNG 무결성 검사는 통과했다. 외곽의 밝은 프린지가 일부 남아 있어 최종 배포 품질 PASS는 아니다. 자연스러운 보행 및 PySide6 실행은 미검증이다.

## 원본 및 측정자료

originals에 현재 첨부 시트와 마스터를 그대로 복사했다. 작업 전후 SHA-256은 동일하다. 시트는 이전 JSON의 SHA-256과 일치한다. 현재 마스터는 이전 JSON과 해시가 다르므로 같은 파일로 간주하지 않았다. 마스터는 디자인 참고와 원본 보존 용도로만 사용했으며 수정하지 않았다. 이전 JSON 전체는 data/prior_measurements.json에 포함했다.

## 처리 방식

원본 1774×887 시트를 x=[0,296,591,887,1183,1478,1774], y=[0,444,887]로 분할했다. 1행 4장과 2행 6장을 추출하고 1행 마지막 두 칸은 투명하게 비웠다. 결과 시트는 1776×888, 셀은 296×444이다.

밝은 중성 배경과 격자를 색상·연결 성분으로 분리했다. 주 연결 성분의 피부와 의상을 유지하고 작은 내부 구멍만 채웠다. 경계 1픽셀 영역의 알파와 배경색 혼합을 추정했다. 이는 추정 매팅이며 정확한 원래 알파의 복원이 아니다. 불투명 내부 RGB는 원본과 동일하다. 투명 픽셀 RGB는 0으로 정리했다.

캐릭터를 확대·축소하거나 포즈를 재생성하지 않았다. 가로 위치는 셀 좌표를 유지한다. 전 실루엣 가운데 정렬은 하지 않았다. 세로 방향으로만 정수 이동하여 alpha>0 최하단을 y=419로 맞췄다. 실제 해부학적 발 접점이나 몸통 앵커는 수동으로 확정하지 않았으므로 잔여 흔들림이 있을 수 있다.

색상 후보는 의미론적 피부·의상·문양 마스크가 아니다. 따뜻한색 조건은 채널차>30 및 R>B+20, 파란색 조건은 셀 상단 90행에서 B>R+5 및 B>G이다. 따뜻한색 후보는 전부 남았고 파란 문양은 정지 비교에서 식별된다. 파란색 후보 중 총 4픽셀은 경계 처리에서 제거되었다. 따라서 문양 전체의 픽셀 단위 무손실 보존을 주장하지 않는다. 불투명 영역 RGB 동일 여부는 모든 프레임에서 참이다.

PNG 10장은 재개방·verify·전체 디코딩을 통과했다. 모두 RGBA 296×444, alpha 최솟값 0·최댓값 255이며 최하단 y=419이다. 상세 bbox, 이동량, 알파 수치는 data/validation.json에 있다.

## 미리보기 및 한계

idle_preview.gif는 4장×320ms, walk_preview.gif는 6장×120ms, 무한 반복이다. 재개방하여 프레임 수·시간·디코딩을 확인했다. GIF는 보기 편하게 회색 배경을 합성한 미리보기이며 실제 투명 에셋은 frames의 PNG다. GIF 색상 양자화 결과를 원본 픽셀 검증에 사용하지 않았다.

어두운 배경의 contact_dark.png를 정지 상태로 시각 확인했다. 질감·격자의 넓은 배경은 제거되었으나 일부 머리·팔·의상 가장자리에 밝은 프린지가 남을 수 있다. 원본에서 배경과 섞인 경계색을 정확하게 복원할 수는 없다. 시간 기반 재생 관찰, 접지 교대, 발 미끄러짐, 마지막→첫 프레임 자연스러움, 120/150/180px 표시, 좌우 반전, v0.2 전환 연결, 실제 Windows/PySide6 투명 오버레이는 미검증이다. 점수는 산출하지 않았다.

## 사용

frames/idle_01.png~idle_04.png, frames/walk_01.png~walk_06.png를 순서대로 사용한다. 공통 기준점은 (148,419), 좌표 원점은 좌상단이다. 축소 시 모든 프레임과 기준점에 같은 배율을 적용한다. 시트 사용 시 셀 크기는 296×444, 배열은 6×2이다. GitHub 업로드는 수행하지 않았다.

data/correct_assets.py는 처리 과정을 보존한 참고 스크립트이며 입력 경로는 이 작업 환경 기준이다. 재실행하려면 입력 파일 경로와 이전 측정자료 경로를 변경해야 한다.
