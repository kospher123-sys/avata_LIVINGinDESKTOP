# v0.10 — 사용자 완성 휴식 이미지 적용

```powershell
.\.venv\Scripts\python.exe prototype_v0_10\main.py --settings
```

저장된 시간표를 바꾸지 않고 휴식 동작을 확인하려면 `--preview-rest`를 추가하거나 트레이 → 동작 → 휴식 모션 확인을 선택합니다. 자동으로 돌아오면 일어서기를 거쳐 시간표에 복귀합니다. 임시 걷기/대기는 즉시 전환하는 확인용 동작입니다.

## 적용한 이미지

- 사용자 ZIP의 512×768 PNG를 픽셀 수정 없이 보존했습니다.
- 측면 서기 1장을 대기에 사용하고, 기존 걷기 6장은 유지합니다.
- 앉기 6장 → 앉은 대기 4장 반복 → 일어서기 6장 순서로 사용합니다.
- 정면 서기/앉은 마스터는 참고 자료로 보관하며 자동 행동에 별도로 넣지 않습니다.
- 새 이미지 바닥 (256,735), 서기 높이 680을 기존 논리 좌표 기준점 (148,419)에 대응시킵니다. 기존 120px 설정에서 서기 높이를 유지하고, 앉은 자세를 같은 키로 확대하지 않습니다.
- 프레임별 시간: 앉기 180/140/160/200/240/260ms, 앉은 대기 600/320/100/600ms, 일어서기 260/240/200/160/140/180ms.

이미지 폴더와 재생/좌표 정보는 assets/characters/aang/clips.json에서 읽습니다. 296×444 기존 에셋과 512×768 새 에셋을 함께 지원하며 원본을 재가공하지 않습니다. 잘못된 선택 동작은 기존 이미지로 대체합니다. 트레이 또는 생활 시간표 탭에서 이미지 다시 불러오기를 사용할 수 있습니다.

## Windows 실행 파일 만들기

```powershell
.\.venv\Scripts\python.exe -m pip install -r prototype_v0_10\requirements-dev.txt
.\.venv\Scripts\python.exe prototype_v0_10\build_windows.py
```

배포 결과: dist/AangOverlay-v0.10/AangOverlay-v0.10.exe. 반드시 폴더 전체를 함께 보관합니다. 실행 파일 옆 assets 폴더의 clips.json과 이미지가 필요합니다.

## 검사

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s prototype_v0_10 -v
```

패키지 해시 46개와 PNG 19장을 독립 검증했습니다. 캔버스/투명도/접지선/프레임별 시간과 화면 렌더링을 검사했으나, 자연스러운 보행/착석의 느낌과 상태 경계의 크기 변화는 사용자 화면 검수가 필요합니다. 원본 보고서도 동작 품질을 WARNING으로 기록합니다.

v0.9의 오류 기록, 절전/화면 복구, 중복 실행 방지, 표시 제어와 설정 탭을 유지합니다. 요일별 시간표는 추가하지 않았습니다.
