# v0.7 — 휴식 이미지 연결 준비

사용자가 제작할 명상·앉기·일어서기 이미지를 연결할 수 있도록 코드를 준비했습니다. 이번 버전에서 새 이미지는 제작하지 않았습니다.

```powershell
.\.venv\Scripts\python.exe prototype_v0_7\main.py --settings
```

- 휴식 이미지가 없으면 기존 IDLE을 사용합니다.
- 이미지가 준비되면 지정 폴더에 넣고 **이미지 다시 불러오기**를 선택합니다.
- 트레이 → 동작 → **휴식 모션 확인**으로 시간표와 무관하게 시험할 수 있습니다. 확인 후 자동으로 돌아오세요.
- 휴식 전환 및 명상 중 이동을 멈추고 일어서기가 끝나면 이동을 재개합니다.
- 선택 이미지 오류는 해당 동작을 제외합니다. 필수 IDLE/WALK 오류는 직전 이미지 세트를 유지합니다.
- v0.6의 탭, 현재시간 버튼, 부분/전체 초기화, 실시간 설정, 시간표, 모니터 선택을 유지합니다.

파일명·크기·접지점·재생 시간·대체 동작은 [휴식 이미지 규격](../docs/REST_ASSET_IMPORT.md)에 정리했습니다. 새 휴식 동작의 실제 외형·자연스러움은 사용자가 이미지를 제공한 후 검수합니다.

자동 검사:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s prototype_v0_7 -v
```

기존 버전과 같은 사용자 설정을 이어받습니다. 이전 버전은 보존했고 동시에 하나의 버전만 실행하는 것을 권장합니다.
