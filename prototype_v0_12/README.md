# v0.12 — 대기 중 가끔 둘러보기

```powershell
.\.venv\Scripts\python.exe prototype_v0_12\main.py --settings
```

- 서 있는 대기 중 가끔 위/아래를 살펴보고 중립 자세로 돌아옵니다.
- 기본 간격은 활동 중 20~40초이며, 다음 대기 상태를 약 0.5초 지켜본 뒤 시작합니다. 걷는 중에는 시작하지 않습니다.
- 둘러보기는 4프레임, 320/500/500/320ms, 한 번만 재생합니다. 재생 중 위치와 대기 타이머를 유지합니다.
- 휴식·앉기/일어서기·다른 동작 확인·직접 모드 선택·드래그가 우선합니다. 일시정지/숨김은 진행을 정지합니다.
- 자동 이동을 끈 서 있는 대기에서도 재생할 수 있습니다. 모든 애니메이션을 멈추려면 일시정지를 사용하세요.
- 설정 창의 동작 확인 탭 또는 트레이에서 **둘러보기 한 번 보기**로 바로 확인할 수 있습니다. 설정/시간표를 저장하지 않습니다.

## 이미지 보정

원본은 assets/characters/aang/source/look_around/original_sheet.png에 보존했습니다. 이미지 수정 도구로 외곽 정리를 시도했지만 저알파 빨강 잔점이 남아 런타임에는 사용하지 않았습니다. 사용자의 별도 승인 후 Python 픽셀 보정으로 원본의 alpha<80을 제거하고 4개 셀을 분리했습니다.

- 프레임 크기는 362×1086, 재그리기·개별 확대/축소 없음.
- 남긴 alpha>=80 픽셀의 RGBA는 원본과 일치합니다. 제거는 경계 휴리스틱이므로 원래 알파의 완전 복원은 아닙니다.
- 발 기준점은 프레임별 메타데이터로 맞추고 배율은 네 프레임에 공통으로 적용합니다.
- extra_clips.json을 사용하므로 기존 휴식 clips.json은 변경하지 않았습니다.
- 재현 스크립트: `python prototype_v0_12/prepare_look_assets.py`. 현재 첨부 시트에 맞춘 크기/분할이므로 다른 입력에 그대로 실행하지 마세요.

[범용 제작·보정·검수 프롬프트](../docs/SPRITE_PRODUCTION_REVIEW_PROMPT.md)에서 다음 이미지 작업에 사용할 템플릿을 제공합니다.

## 검사와 Windows 배포

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s prototype_v0_12 -v
.\.venv\Scripts\python.exe prototype_v0_12\build_windows.py
```

배포 폴더는 dist/AangOverlay-AIR_BLAST-V3입니다. exe와 assets 폴더 전체가 필요합니다. 이번 동작은 원본의 머리/시선 변화만 사용하며 몸통의 미세한 변형이나 상태 경계의 시각적 차이는 사용자 화면 검수가 필요합니다.

## AIR_BLAST V3

일반 실행 파일도 V3 하나만 사용합니다. 구버전 앱은 트레이에서 종료한 뒤 새 폴더의 exe를 실행하세요. 배포 폴더는 `dist/AangOverlay-AIR_BLAST-V3`이며 exe와 assets를 함께 유지합니다.

FLOW_FIELD는 자연 길이로 한 번만 표시하고, 전경 칼바람 네 개는 시간·위치·속도·크기를 독립적으로 계산합니다. 전방 지속 시간은 1.2초입니다. 드래그 중에도 진행 중 모션을 유지합니다.

설정의 **모든 동작 살펴보기**는 실제 로드된 동작을 등록 순서대로 한 번씩 재생합니다. 빈 동작은 건너뜁니다. 설정을 저장하거나 위치를 이동시키지 않습니다.

현재 이미지의 FLOW 06 잔상, FLOW 08 길이/루프는 품질 검수 대기입니다. 자세한 실행 경로, 검증 한계, 이전 버전 복구는 [V3 검증 기록](../docs/AIR_BLAST_V3_RUNTIME.md)을 참고하세요.
